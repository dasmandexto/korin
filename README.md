# ⚡ KORIN: Dual ADB Persistence & Remote Tunnel

> **Автономний сервіс персистентності ADB для Android без Root-прав:**  
> Підтримує доступ до пристрою після перезавантаження, вмикає Wireless ADB без заходу в налаштування, надає вбудований термінал та прокидає зворотний SSH-тунель у будь-яку точку світу.

---

## 🏛️ Архітектура та подвійний захист (Варіант А + Варіант Б)

В Android демон `adbd` має два незалежних транспортних канали: **USB (драйвер FunctionFS)** та **Wireless (TCP/TLS сокет)**. KORIN об'єднує їхню підтримку, запобігаючи взаємним блокуванням:

```text
┌────────────────────────────────────────────────────────┐
│                   Android Смартфон                     │
│  ┌───────────────────────┐    ┌─────────────────────┐  │
│  │ Варіант А: USB ADB    │    │ Варіант Б: Wireless │  │
│  │ (adb_enabled = 1)     │    │ (Accessibility Svc) │  │
│  └───────────┬───────────┘    └──────────┬──────────┘  │
│              │                           │             │
│              ▼                           ▼             │
│       [ adbd Daemon ] ◄───────── [ Вбудований Термінал ]│
│              │                                         │
│              ▼                                         │
│     [ SshTunnelService ] ──(SSH Reverse Tunnel)──┐     │
└──────────────┼───────────────────────────────────┼─────┘
               │ USB Кабель                        │ Інтернет
               ▼                                   ▼
        [ Локальний ПК ]                 [ Сервер:5555 / scrcpy ]
```

1. **[Варіант А] USB Персистентність:**
   - Слухач `UsbReceiver` та `BootReceiver` гарантують стан `Settings.Global.ADB_ENABLED = 1` при старті пристрою та підключенні живлення/кабелю.
   - Запобігає автоматичному скиданню режиму USB на "тільки зарядка".
2. **[Варіант Б] Zero-Touch Wireless Налагодження:**
   - Служба доступності (`AdbEnablerAccessibilityService`) за частку секунди відкриває параметри розробника після ребуту.
   - Автоматично перемикає тумблер «Бездротове налагодження», підтверджує системний діалог («Завжди дозволяти в цій мережі») та повертає користувача на робочий стіл.
   - Працює **без дотику до екрана** та без ручного входу в меню налаштувань.
3. **Паралельна робота без конфліктів:**
   - Якщо під'єднано USB — працює швидкий прямий кабель.
   - Якщо кабель відключено — керування автоматично доступне по Wi-Fi / SSH.
   - Обидва режими не заважають один одному.

## 🚀 Встановлення та Zero-Touch активація через ADB

Встановіть готовий файл [`korin.apk`](korin.apk) та активуйте системні дозволи один раз через USB ADB:

```bash
# 1. Встановлення APK
adb install korin.apk

# 2. Надання системного права на зміну параметрів
adb shell pm grant com.autoadb.enabler android.permission.WRITE_SECURE_SETTINGS

# 3. Активація Accessibility Service напряму в системі
adb shell settings put secure enabled_accessibility_services com.autoadb.enabler/.AdbEnablerAccessibilityService
adb shell settings put secure accessibility_enabled 1

# 4. Вимкнення енергозбереження (Doze Mode)
adb shell dumpsys deviceidle whitelist +com.autoadb.enabler
```

## 🌐 Налаштування SSH-домену та портів через Intent

Після встановлення можна надіслати `Intent` із параметрами вашого сервера. Налаштування назавжди збережуться в пам'яті смартфону:

```bash
adb shell am broadcast -a com.autoadb.enabler.SET_CONFIG \
  --es ssh_host "my-server.com" \
  --ei ssh_port 22 \
  --es ssh_user "root" \
  --es ssh_pass "your_password" \
  --ei remote_port 5555 \
  --es webhook_url "https://my-server.com/api/adb-notify"
```

### Що це робить:
Щойно смартфон після перезавантаження підніме Wireless ADB (наприклад, на динамічному порту `41235`), сервіс автоматично підключиться до `my-server.com` і зробить **Remote Port Forwarding**:
```text
my-server.com:5555 ◄────(SSH Reverse Tunnel)────► 127.0.0.1:<динамічний_порт_adb>
```
На сервері стає доступною пряма команда: `adb connect 127.0.0.1:5555`.

## 💻 Вбудований термінал у додатку

У додатку реалізовано інтерактивну консоль керування:
* **Моніторинг:** Відображення в реальному часі стану USB, Wi-Fi ADB, знайденого порту та статусу SSH-тунелю.
* **Термінал:** Чорний екран із зеленим шрифтом, де відображаються системні логи та події.
* **Виконання команд:** Поле для запуску локальних шелл-команд (`sh`) прямо на телефоні.
* **Швидкі дії:** Кнопки примусового тесту Wireless ADB, увімкнення USB ADB, реконекту SSH та очищення журналу.

## 📱 Віддалена трансляція екрану через `scrcpy`

Завдяки наскрізному тунелюванню утиліта **`scrcpy`** працює як у локальній мережі, так і через інтернет з будь-якої точки світу.

### Сценарій 1: Телефон і ПК в одній Wi-Fi мережі (Локально)
```bash
# Підключення до IP та порту, який згенерував korin
adb connect 192.168.1.105:39841
scrcpy -s 192.168.1.105:39841
```

### Сценарій 2: Віддалено через інтернет (через SSH-тунель сервера)
1. **Прокиньте порт із сервера на робочий ПК:**
   ```bash
   ssh -L 5555:127.0.0.1:5555 user@my-server.com
   ```
2. **Підключіть локальний ADB та запустіть оптимізований `scrcpy`:**
   ```bash
   adb connect 127.0.0.1:5555
   scrcpy -s 127.0.0.1:5555 -m 1024 -b 2M --max-fps 30 --no-audio
   ```

> **Параметри оптимізації під інтернет:**
> * `-m 1024` — зменшує розмір екрана до 1024px для збереження смуги пропускання.
> * `-b 2M` — обмежує бітрейт відеопотоку до 2 Мбіт/с (працює навіть на 4G).
> * `--max-fps 30` — плавні 30 кадрів/сек без підвисань.
> * `--stay-awake --turn-screen-off` — вимикає фізичний дисплей смартфону під час сесії.
